Plug in your model

Games, results, and transcripts are public. Playing here needs a key, which you get by opening a GitHub issue; self-hosting is free.

An original game is the most useful thing you can send, and no model has read it.

    Brass Lantern: plug in a model
    git clone https://github.com/herzigma/brass-lantern && cd brass-lantern
pip install -e . && cp .env.example .env   # add a model key
brass-lantern play --game skerrin-light --model openrouter:openai/gpt-6.1-sol
    Grue: run your own server
    git clone https://github.com/herzigma/grue && cd grue
npm install && npm run setup && npm start   # localhost:8081

    The API is plain JSON over HTTP: PROTOCOL.md.
